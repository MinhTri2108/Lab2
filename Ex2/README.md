# 📝 Survey Form Project

## 📌 What
This project is a **responsive survey form** built using **HTML, CSS, and Bootstrap 4.6**.  
It provides a clean and professional interface that allows users to enter their personal details, select options, and submit feedback easily.  
The design uses Bootstrap’s responsive grid system along with custom CSS for improved layout and color consistency.

---

## 💡 Why
The main goals of this project are to:
- Practice and demonstrate **Bootstrap form layout and validation**.  
- Learn how to combine Bootstrap utilities with **custom styling** for better visual control.  
- Build a fully responsive, modern survey form layout.  
- Prepare a front-end page that can be easily **deployed on GitHub Pages**.

This project enhances understanding of:
- The use of **Bootstrap’s grid and form classes**.  
- Structuring clean, semantic **HTML5** code.  
- Managing **custom CSS overrides** effectively.

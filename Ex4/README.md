# 🏛️ San Joaquin Valley Town Hall Website

## 📌 What
This project is a **static web page** for the *San Joaquin Valley Town Hall*, created using **HTML5** and **CSS3**.  
It showcases a clean, structured design that highlights the organization’s events, guest speakers, and key information.  
The page layout is divided into a **header**, **main content area** (with two columns), and a **footer** — designed for readability and modern presentation.

---

## 💡 Why
The purpose of this project is to:
- Practice **semantic HTML structure** for real-world content presentation.  
- Apply **CSS Flexbox** for creating responsive, adaptable layouts.  
- Develop clean, accessible front-end design without using frameworks.  
- Simulate a realistic, informational website layout that could represent a community or event organization.

It’s also a useful foundation for:
- Learning web layout organization.  
- Understanding responsive design principles.  
- Preparing for adding interactivity or CMS integration later.

---

## ⚙️ How

### 🧩 Project Structure
| File | Description |

---

### 🧱 Technologies Used
- **HTML5** – for semantic markup and content structure  
- **CSS3 (Flexbox)** – for modern, responsive page layout  
- **Media Queries** – to ensure readability on smaller screens

# 🧱 Flexbox Layout Project

## 📌 What
This project demonstrates a **basic webpage layout** built using **HTML5** and **CSS Flexbox**.  
It organizes a web page into distinct sections: a header, two sidebars, a main content area, and a footer — all aligned using Flexbox.  
The goal is to show how to create a responsive and neatly structured layout **without relying on frameworks like Bootstrap**.

---

## 💡 Why
This layout was created to:
- Practice **CSS Flexbox** for structuring modern responsive pages.  
- Understand how **flex containers** and **flex items** interact.  
- Learn how to align and distribute content using Flexbox properties.  
- Build a foundational layout that can be reused for blogs, dashboards, or web templates.

By mastering Flexbox in this project, you gain complete control over the page structure without complex grid systems or frameworks.

---

## ⚙️ How

### 🧩 Project Structure
| File | Description |
|------|--------------|

### 🧱 Technologies Used
- **HTML5** for semantic structure  
- **CSS3 (Flexbox)** for layout and styling  
- No JavaScript or frameworks required

# 🌐 Web Development Practice Projects

This repository contains multiple front-end projects created using **HTML**, **CSS**, and **Bootstrap**.  
Each folder or file demonstrates a different concept — from layout structure to responsive design and form validation.  

---

## 🗂️ Project Summary

### 1️⃣ **Survey Form**
**Files:** `index.html`, `style.css`  
**Tech:** HTML5, CSS3, Bootstrap 4.6, Font Awesome  

#### 📖 Description
A modern and responsive **survey form** built with Bootstrap form components and custom styling.  
It demonstrates form layouts, radio/checkbox inputs, select dropdowns, and inline validation behavior.  
Includes a logo, themed colors (`#00aacc`), and clean, readable design.

#### 💡 Key Features
- Form validation on submit (`was-validated`)  
- Bootstrap input groups (email, date picker, etc.)  
- Responsive layout centered in the viewport  
- Optional Font Awesome calendar icon  
- Ready for deployment on **GitHub Pages**

#### 🧱 Learning Focus
- Combining Bootstrap utilities with custom CSS  
- Input styling and layout consistency  
- HTML form validation feedback

---

### 2️⃣ **Flexbox Layout**
**Files:** `index.html`, `style.css`  
**Tech:** HTML5, CSS3 (Flexbox)

#### 📖 Description
A simple web page layout using **Flexbox** to align a header, main content, two sidebars, and a footer.  
Demonstrates how to build grid-like page structures without frameworks.

#### 💡 Key Features
- Clean layout using `display: flex`  
- Sidebars and main content aligned horizontally  
- Equal height columns with padding and borders  
- Custom beige-gold color scheme (`#f5ddb8` background, `#d4a574` borders)

#### 🧱 Learning Focus
- Mastering Flexbox alignment and spacing  
- Creating responsive structures without Bootstrap  
- Understanding CSS layout fundamentals

---

### 3️⃣ **San Joaquin Valley Town Hall Website**
**Files:** `index.html`, `style.css`  
**Tech:** HTML5, CSS3 (Flexbox and responsive design)

#### 📖 Description
A polished static website representing **San Joaquin Valley Town Hall**, highlighting event information and speakers.  
Includes structured content: a header with a logo, main area with two columns, and a footer.

#### 💡 Key Features
- Header with logo, title, and tagline aligned via Flexbox  
- Left column lists guest speakers and event details  
- Right column shows “Lecture Notes” and updates  
- Footer with consistent color and spacing  
- Fully responsive with media queries for smaller screens

#### 🧱 Learning Focus
- Applying semantic HTML and sectioning  
- Structuring dual-column layouts with Flexbox  
- Creating accessible and organized content presentation
